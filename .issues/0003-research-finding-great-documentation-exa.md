## Question

Find examples of excellent project documentation across a range of domains and scales. Prioritize sources that demonstrate the universal truths (navigability, teaching, versioning, etc.). For each example, capture: what makes it excellent, which truths it exemplifies, the domain and scale of the project, and what the `documentation` skill can learn from it. The examples should be modular files the skill can ship with.

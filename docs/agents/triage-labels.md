# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

Every issue carries exactly one `kind:` label and one `state:` label.

| Canonical role | Label in our tracker | Meaning |
|---|---|---|
| `bug` | `kind:bug` | Something is broken |
| `enhancement` | `kind:enhancement` | New feature or improvement |
| `needs-triage` | `state:needs-triage` | Needs evaluation |
| `needs-info` | `state:needs-info` | Waiting on reporter |
| `ready-for-agent` | `state:ready-for-agent` | Fully specified, ready for agent |
| `ready-for-human` | `state:ready-for-human` | Needs human implementation |
| `wontfix` | `state:wontfix` | Will not be actioned |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.

Edit the right-hand column to match whatever vocabulary you actually use.

## Evaluation criteria

- **Usefulness** — Does it solve a real problem in everyday coding work?
- **Maintenance** — Is the skill actively maintained? Does it pin dependencies?
- **Transparency** — Can we understand what it does without running it?
- **Size** — Does it pull in heavy dependencies?
